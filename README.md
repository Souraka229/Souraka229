## `> ./projects.sh`

### 🍽️ Restafy · Restaurant management for francophone West Africa
**Founder & lead engineer** · [restafy.shop](https://restafy.shop) · 0% commission model

Restaurants in West Africa run on spreadsheets, paper tickets and WhatsApp orders. Restafy replaces that with one platform.

| | |
|---|---|
| **Orders** | Dine-in, takeaway and delivery in a single dashboard, plus QR menus |
| **Kitchen** | Real-time Kitchen Display System (KDS) that routes orders to the right station |
| **Payments** | Mobile money: MTN MoMo, Moov Money, Celtiis Cash |
| **Insights** | Sales tracking, inventory, simple growth metrics |
| **Design** | Built for low-connectivity environments, made for maquis and small restaurants |

### 🤖 ReturnWise · AI-assisted migration support
**🏆 Winner, IOM Morocco Hackathon** · Team Second Chance Lab (4 engineers + 1 PM) · with Benin AI Community, EU-funded programme

AVRR agents lose hours juggling spreadsheets and documents to understand a single case, while migrants struggle to know which documents they need or where their file stands.

- **For agents:** explainable vulnerability scoring, suggested reintegration pathways, field-monitoring dashboards, a contextual assistant for information retrieval
- **For beneficiaries:** a clear guidance portal, document checklists, live application status, direct contact support
- **Principle:** *AI assists, humans decide.* It structures, suggests, compares and alerts, but never replaces human judgment in sensitive contexts.

**My role:** system architecture · data pipeline · ML vulnerability scoring

`Python` · `Machine Learning` · `React` · `Node.js` · `PostgreSQL` · `Supabase`

## `> cat manifesto.txt`

```
The gap between global tech and African business reality isn't a bug.
It's the product brief.

Most platforms treat Africa as an afterthought:
  ✗ no offline-first design
  ✗ no local payment integration
  ✗ no feel for how commerce actually moves on the ground

I don't build for Africa from the outside. I build from the inside,
which means designing around constraints, not past them.

A restaurant manager in Cotonou shouldn't need a laptop farm to get paid.
A migrant shouldn't need a tech degree to understand their case.
An SME shouldn't need venture capital to exist online.

Build from inside the constraint, and you don't just solve for Africa.
You build products the world ends up following.

If you're young, African and tech-driven: apply anyway.
```
